# Project memory

## Product intent & audience

- Aplicación con panel de administración y panel de restaurante
- App pública con menú de clientes
- Audiencia hispanohablante; la interfaz debe estar en español

## Brand personality & voice

- Comunicación directa y concisa
- Respuestas en español

## Visual design & UX direction

- PWA prevista pero aún no configurada
- No hay detalles estéticos suficientes para inferir paleta, tipografía o layout

## Decisions, constraints & rationale

- Framework: Vite + React
- Páginas de admin: ya traducidas al español
- Páginas de restaurante y componentes compartidos: pendientes de traducción
- App pública y menú de clientes: pendientes de implementación/traducción
- PWA: pendiente de configuración
- Restricción: límite mensual de cuenta gratuita puede interrumpir tareas largas

## Open questions & assumptions

- ¿Se debe continuar con lo pendiente tras confirmación del usuario?
- ¿Se cambiará de plan o se renovará para evitar interrupciones por límite de uso?
- Se asume que la traducción al español abarca toda la app, no solo admin
